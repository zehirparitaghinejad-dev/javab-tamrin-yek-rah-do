# javab-tamrin-yek-rah-do
### تمرین شماره ۱ 

در این تمرین با مفاهیم پایه پایتون کار کردم:

* دریافت ورودی با `input`
* تبدیل ورودی به عدد با `int`
* استفاده از شرط‌های `if` و `elif`
* نمایش نتیجه با `print`

برنامه ساعت را از کاربر دریافت می‌کند و بر اساس ساعت واردشده، پیام مناسب مثل «صبح بخیر»، «بعد از ظهر بخیر» یا «شب بخیر» نمایش می‌دهد.
